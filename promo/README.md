# CINEMA intro player

Integrated from the approved local HTML candidate on 2026-09-26. The TOP now uses the approved v3 hero screen: the home heading for 4.6 seconds, the original CINEMA film (with a 1.6-second phone hold), then a return to the home heading instead of the closing URL card. Silent. The 49-second standalone bilingual player remains available at `player.html?film=ja|en`. Android is not promoted in the film.

Runtime source: `player.html`, `film.js/css`, `cinema.js/css`, `night-cut.js/css`, shared `pv-engine.js` and `pv-base.css`, `player.js/css`, `embed.js/css`, `scenes.js`, and `assets/`. These are the editable production sources. The earlier comparison prototypes are not runtime dependencies.

All photographs are michikusa's own. Captured product screens contain no third-party photographs; map attribution is retained. Lightweight source provenance and hashes are preserved in the operating repo at `.codex-local/previews/promo-pv-html-0926/assets-report.json` and `night-assets.json`. The source storyboard and inherited render history are documented there. Original synthesized audio only, no station melody.

Marketing count is `50+` in the film, its transcript and reduced-motion cards. TOP uses “50以上の景色” / “50+ views”. Adding a spot does not require edits. The source data remains authoritative for actual list totals. Night illumination/berthing footnotes are intentionally omitted from this introduction at the owner's request.

The hero runtime is `../hero-cinema.js/css` and `hero-stage.html/js/css`. The static home heading, description, poster and four entry cards live in `../index.html`; English is generated by `scripts/generate-spot-pages.mjs`. `hero-stage.html` owns the copied stage markup and reuses the unchanged film renderers. Keep stage DOM IDs aligned with `player.html` when updating the renderers. No preview directory is a runtime dependency.

The stage is a noindex utility iframe, not a new editorial landing route. TOP passes language with `?film=ja|en`. Manual chapter navigation stops automatic progression and holds the selected chapter at its end. Pause works inside a chapter; arrow, pointer swipe, horizontal wheel and keyboard navigation are supported. The hero does not run offscreen or in hidden tabs. Reduced-motion and Save-Data keep the initial poster without loading the iframe until a manual request; selected chapters are still images. The current candidate autoplays on each page load; session-once remains an owner decision. Failure leaves the real HTML heading and entry cards usable.

TOP no longer starts the `intro_film_*` dialog events. The new `hero_film_chapter` (chapter and input method) and `hero_film_auto_complete` events use the existing consent-aware gtag only when available. Entry cards retain `lp_cta_click` and value-path events; train selection is `hero-card-train`. These describe use, not satisfaction or causal effect. The retired `intro-film.js/css` are not loaded or distributed by the TOP; the standalone player keeps its explicit sound control.

Runtime files are registered by `scripts/generate-content-manifest.mjs`. Android bundling is a separate follow-up; do not synchronize the new TOP into mobile without registering the dependencies and checking the app's webview behavior.
