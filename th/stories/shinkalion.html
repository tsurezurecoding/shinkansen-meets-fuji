05 / หุ่นยนต์แปลงร่างชินคันเซ็น

ชินคาเลียน (Shinkalion) ชินคันเซ็นของจริงแปลงร่างได้

ตัวรถสีขาวจะเปลี่ยนเป็นอะไร เมื่อชมการแปลงร่างของ N700S แล้ว คราวนี้ไปพบรถไฟของจริงกัน

รถไฟจริง / N700A

สารบัญบทความ

  1. 01ชินคันเซ็นที่คุ้นตา กลายเป็นตัวเอกในเรื่อง
  2. 02ใน Transformers ก็มีชินคันเซ็น
  3. 03จินตนาการถึงฐานลับจากพิพิธภัณฑ์ในนาโกย่า
  4. 04ที่เกียวโต มีพิพิธภัณฑ์อยู่เลยหน้าต่างไป
  5. 05ชินคันเซ็นขบวนถัดไปอาจดูต่างไปเล็กน้อย

รถไฟสีขาวคาดแถบสีน้ำเงิน รถที่พบเห็นบนชินคันเซ็นสายโทไคโดจะกลายร่างเป็นหุ่นยนต์ยักษ์ได้ไหม? จินตนาการนี้กลายเป็นเรื่องราวในชินคาเลียน (Shinkalion)

แม้ไม่เคยรู้จักเรื่องนี้ ก็เริ่มต้นได้จากชินคันเซ็นที่พบระหว่างเดินทาง ลองรู้จักชื่อขบวนจริง ดูรูปร่างในเรื่อง แล้วแวะไปพิพิธภัณฑ์รถไฟที่นาโกย่าหรือเกียวโต ขอชวนออกนอกเส้นทางสักนิด ระหว่างโลกของยานพาหนะกับเรื่องเล่า

01

ชินคันเซ็นที่คุ้นตา กลายเป็นตัวเอกในเรื่อง

เด็กชายผู้รักรถไฟกลายเป็นคนขับ

ฮายาโตะ ฮายาสึงิ ตัวเอกของอนิเมะโทรทัศน์ซีซันแรก เป็นเด็กชายที่รักรถไฟและฝันอยากขับชินคันเซ็น เด็ก ๆ ได้รับเลือกให้เป็นคนขับและควบคุมชินคาเลียน หุ่นยนต์ที่สถาบันวิจัยลับพัฒนาขึ้นเพื่อต่อกรกับศัตรูตัวมหึมา พวกเขาร่วมมือกับผู้ใหญ่ในสถาบันเพื่อปกป้องผู้คน[10]

เสน่ห์ของเรื่องนี้คือความสนุกจากการนั่งชินคันเซ็นและความผูกพันกับขบวนรถเชื่อมต่อไปสู่การผจญภัยของเหล่าฮีโร่ได้โดยตรง E5 สีเขียวที่มุ่งหน้าไปโทโฮคุ และ N700A สีขาวคาดน้ำเงินที่วิ่งบนสายโทไคโด การรู้จักชินคันเซ็นแต่ละรุ่นและแต่ละเส้นทางยังเพิ่มความสนุกในการทำความรู้จักหุ่นยนต์ที่ปรากฏในเรื่อง

ชินคาเลียนมีหุ่นยนต์แปลงร่างที่สร้างจากชินคันเซ็นซึ่งมีอยู่จริง ในอนิเมะโทรทัศน์ซีซันแรก 『新幹線変形ロボ シンカリオン』 คิโยสุ ริวจิเป็นผู้ควบคุม 「シンカリオン N700Aのぞみ」 N700A ในภาพจึงเป็นรถรุ่นหนึ่งที่เชื่อมโยงกับเรื่องนี้[1]

PV พิเศษที่เปิดเรื่องเผยแพร่ในปี 2020 เพื่อฉลองการเปิดตัว N700S[9] ส่วน 『シンカリオン チェンジ ザ ワールド』 เป็นอีกเรื่องหนึ่งที่มี 「シンカリオン N700Sのぞみ」 หุ่นยนต์ตัวนี้แปลงร่างมาจากตู้หัวขบวน N700S ความแตกต่างระหว่างตัวอักษร A กับ S ท้ายชื่อจึงเป็นจุดเริ่มต้นให้ค้นหาเรื่องราวต่อได้[2]

แม้แต่ปลั๊กไฟก็กลายเป็นพลังของหุ่นยนต์

ตัว S ใน N700S มาจากคำว่า 「Supreme」 ซึ่งหมายถึงยอดเยี่ยมที่สุด ชื่อ 「スプリームモード」 ของหุ่นยนต์ใน PV ตอนต้นก็แสดงให้เห็นความเชื่อมโยงกับรถไฟจริง[9]

รายละเอียดที่เชื่อมโยงกันไม่ได้มีแค่ชื่อและรูปลักษณ์เท่านั้น แบตเตอรี่สำหรับขับเคลื่อนด้วยตัวเองและเต้ารับสำหรับอุปกรณ์พกพาที่ทุกที่นั่งของ N700S จริง ถูกนำไปใช้เป็นแนวคิดของหุ่นยนต์และของเล่นในปี 2020 ด้วย แบตเตอรี่กลายเป็น 「スプリームドラゴン」 ที่ช่วยในการต่อสู้ ส่วนเต้ารับกลายเป็นปลั๊กสำหรับท่าไม้ตาย เทคโนโลยีจริงที่ช่วยให้การเดินทางสะดวกสบายและปลอดภัย แปรเปลี่ยนเป็นพลังของหุ่นยนต์ในเรื่องเล่า[9]

ชื่อ ‘โนโซมิ’ เหมือนกัน แต่รุ่นรถมีหลายแบบ

‘โนโซมิ’ คือชื่อขบวนรถ ส่วน N700A และ N700S คือรุ่นของตัวรถ ขบวนที่คุณโดยสารอาจไม่ใช่ N700S แม้จะเป็น ‘โนโซมิ’ ครั้งหน้าเมื่อเห็นชินคันเซ็นที่สถานี ลองสังเกตโลโก้บนตัวรถด้วย[3]

02

ใน Transformers ก็มีชินคันเซ็น

เมื่อได้ยินว่ายานพาหนะแปลงร่างเป็นหุ่นยนต์ หลายคนอาจนึกถึง Transformers แม้จะเป็นคนละเรื่องกับชินคาเลียน แต่ของเล่นทั้งสองชุดสร้างสรรค์โดย Takara Tomy[4]

ใน Transformers ยังมี 「トレインボットショウキ」 ซึ่งแปลงร่างมาจากชินคันเซ็นซีรีส์ 0 สายโทไคโด เว็บไซต์ทางการของ Takara Tomy มีภาพให้เปรียบเทียบระหว่างรถซีรีส์ 0 ที่มีหัวมนกับร่างหุ่นยนต์[5]

โชกิเป็นหนึ่งใน Trainbot ที่แปลงร่างจากขบวนรถไฟและปรากฏในอนิเมะโทรทัศน์ 『トランスフォーマー ザ・ヘッドマスターズ』 ของเล่น MPG แปลงร่างจากซีรีส์ 0 เป็นหุ่นยนต์ แล้วรวมร่างกับอีกห้าตัวเป็น 「ライデン」 ขนาดใหญ่ โดยโชกิทำหน้าที่เป็นส่วนอก นี่คือกลไกที่ขบวนรถเดียวแสดงรูปร่างต่างกันได้ทั้งจากการแปลงร่างและการรวมร่าง[5]

แนวคิดที่ชินคันเซ็นกลายเป็นหุ่นยนต์มีอยู่ทั้งใน Transformers และชินคาเลียน แต่รถไฟรุ่นเดียวกันอาจมีรูปร่างหุ่นยนต์และบทบาทในเรื่องต่างกันเมื่ออยู่คนละผลงาน ลองชมทั้งสองเรื่องแล้วจะเห็นว่ารถไฟญี่ปุ่นเป็นแรงบันดาลใจให้กับงานสร้างสรรค์มาเนิ่นนาน

ถ้าชอบยานพาหนะที่แปลงร่างได้ รถไฟญี่ปุ่นก็เพิ่มความสนุกให้อีกอย่าง เพราะก่อนเป็นหุ่นยนต์ รถไฟเหล่านั้นคือชินคันเซ็นที่เคยรับผู้โดยสารและวิ่งจริง

03

จินตนาการถึงฐานลับจากพิพิธภัณฑ์ในนาโกย่า

ในอนิเมะโทรทัศน์ซีซันแรก สถาบันวิจัยวิวัฒนาการชินคันเซ็นสาขานาโกย่าตั้งอยู่ใต้ดินของพิพิธภัณฑ์รถไฟและรถไฟแม่เหล็กลอยตัว ที่นี่ยังเป็นฐานของเรื่องซึ่งมี 「シンカリオン N700Aのぞみ」 ประจำการอยู่ด้วย[1]

แน่นอนว่าฐานลับใต้ดินเป็นเรื่องแต่ง ที่พิพิธภัณฑ์จริง คุณจะได้ชมชินคันเซ็นรุ่นต่าง ๆ ตั้งแต่ซีรีส์ 0, 100, 300 ไปจนถึง 700 อย่างใกล้ชิด แค่เปรียบเทียบรูปทรงส่วนหัวก็ชวนให้สัมผัสช่วงเวลาที่นำมาสู่ชินคันเซ็นที่เราโดยสารในปัจจุบันได้[6]

เรื่องราวยังเชื่อมโยงกับพื้นที่ด้วย คิโยสุ ริวจิ ผู้ควบคุม N700A แห่งสาขานาโกย่าเป็นนักเรียนมัธยมต้นจากจังหวัดไอจิ และเป็นคนขับที่ได้รับการฝึกจากโฮคุโตะ พ่อของฮายาโตะในเกียวโต เขายังนำประสบการณ์คาราเต้มาประยุกต์ใช้ในการต่อสู้ของหุ่นยนต์ นาโกย่ากับเกียวโตจึงไม่ใช่เพียงชื่อสถานที่ในฉาก แต่เป็นเมืองที่ผู้คนเดินทางไปมาและสืบทอดเทคโนโลยีด้วย[10]

มีเหตุผลที่เลือกพิพิธภัณฑ์จริงมาเป็นฐานในเรื่อง บทสนทนาทางการกับทีมสร้างซีซัน 1 และ 2 อธิบายว่า พวกเขากำหนดให้ฐานอยู่ใต้พิพิธภัณฑ์รถไฟเพื่อให้ผู้ชมรู้สึกถึงความเชื่อมโยงกับโลกจริง[7]

ลงจากรถไฟเพื่อไปเยือน
จากสถานีนาโกย่า นั่งรถไฟสายอาโอนามิไปสถานีคินโจฟุโตะ จากนั้นเดินประมาณ 2 นาที ที่นี่ไม่ได้มองเห็นจากหน้าต่างชินคันเซ็น แต่เป็นสถานที่แวะเที่ยวเมื่อคุณลงที่นาโกย่า วิธีเดินทางอย่างเป็นทางการ

04

ที่เกียวโต มีพิพิธภัณฑ์อยู่เลยหน้าต่างไป

ทางฝั่งตะวันตกของสถานีเกียวโต บางครั้งคุณมองเห็นภายนอกพิพิธภัณฑ์รถไฟเกียวโตจากหน้าต่างชินคันเซ็นได้ ป้ายชื่อพิพิธภัณฑ์อยู่ถัดจากสายไฟเหนือรางและขบวนรถสินค้า

พิพิธภัณฑ์แห่งนี้ปรากฏในอนิเมะโทรทัศน์ซีซันแรกเช่นกัน โดยมีฉากใต้ดินเป็นที่ตั้งของสถาบันวิจัยสาขาเกียวโต JR West ก็กล่าวถึงแนวคิดนี้ในประกาศกิจกรรมร่วมมือเมื่อปี 2019[8]

ภายในจัดแสดงชินคันเซ็นของจริง เช่น ตู้รถหมายเลข 1 ของซีรีส์ 0 และซีรีส์ 500 คุณสามารถดูซีรีส์ 0 ซึ่งเป็นต้นแบบของโชกิ แล้วเปรียบเทียบกับซีรีส์ 500 ที่โดดเด่นด้วยส่วนหัวเรียวยาว จากชินคันเซ็นที่เห็นในอนิเมะและของเล่น สู่รถไฟจริงที่เป็นต้นแบบ ความสนใจที่เริ่มจากสองเรื่องราวเชื่อมต่อกับประวัติศาสตร์รถไฟสายเดียวกัน[11]

บางวันอาจมองผ่านหน้าต่างเพียงชั่วครู่ บางวันอาจลงที่เกียวโตเพื่อไปเยือน พอรู้ว่าที่นี่เคยเป็นฐานในเรื่อง อาคารที่อยู่เลยรางรถไฟไปก็ชวนให้สนใจขึ้นมา

ลงจากรถไฟเพื่อไปเยือน
จากสถานีเกียวโต นั่งสายซากาโนะไปสถานีอุเมะโคจิเกียวโตนิชิ แล้วเดินประมาณ 2 นาที จากหน้าต่างรถไฟจะเห็นเพียงภายนอก หากต้องการชมสิ่งจัดแสดงต้องเข้าไปในพิพิธภัณฑ์ วิธีเดินทางอย่างเป็นทางการ

ภาพแสดงสภาพ ณ วันที่ถ่าย ขบวนรถที่วิ่งอยู่ด้านหน้าหรือสภาพอากาศอาจทำให้มองเห็นต่างออกไป โปรดตรวจสอบวันเปิดทำการและนิทรรศการปัจจุบันจากเว็บไซต์ทางการของพิพิธภัณฑ์แต่ละแห่ง

05

ชินคันเซ็นขบวนถัดไปอาจดูต่างไปเล็กน้อย

ไม่จำเป็นต้องดูเรื่องทั้งหมดก่อนออกเดินทาง ลองมองหาโลโก้ N700A ที่สถานี ดูรูปร่าง N700S ในอนิเมะ หรือเปรียบเทียบหัวมนของซีรีส์ 0 กับรถรุ่นปัจจุบันในพิพิธภัณฑ์

แม้แต่ชินคันเซ็นที่เห็นเป็นประจำก็ยังมีเรื่องราวที่เราไม่เคยรู้ ลองพกการค้นพบเล็ก ๆ นี้ติดตัวไปในการเดินทางครั้งหน้า
