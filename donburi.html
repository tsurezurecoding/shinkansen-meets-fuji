日本の食を旅する DONBURI

牛丼から、旅のごちそうまで。

知っている店があると、
知らない街を、もう少し歩ける。

観光の合間に食べる牛丼。鶏と卵がやさしく合わさる親子丼。そして、まぐろやうなぎを目当てに出かける一食。日本の「丼」を知ると、旅の食事に選択肢が増えます。

午前中は歩き回って、気がつけば昼を過ぎている。夕食は予約してあるけれど、それまではまだ長い。そんなとき、街で見かける牛丼チェーンを知っていると、温かい一食にたどり着きやすくなります。

まず覚えたい看板は、吉野家、すき家、松屋。温かいごはんを気軽に食べられ、ひとりでも入りやすい店です。毎食の店を決めておかなくても、この三つを知っていれば、その日の歩き方に合わせて食事を選べます。

牛丼（gyudon）は、ごはんの上に、甘辛く煮た薄切りの牛肉と玉ねぎをのせた料理。こうして具をごはんに重ねる料理を、日本では丼（どんぶり / donburi）と呼びます。かつ丼も、親子丼も、その仲間。気軽な昼食から、旅の楽しみにしておきたい一杯まで、同じ「丼」の名前の下に並んでいます。

01 / 街で見つかる、温かい一食

まずは、この看板を目印に。

初めてなら、まずは追加のトッピングがない牛丼の「並盛」を。たれをまとった牛肉と、少し甘みのある玉ねぎを、ごはんと一緒に味わってみてください。紅しょうがや七味は、好みに合わせて少しずつ。食べ進めながら味を変えるのも、牛丼の楽しみです。

三つのチェーンは、どこも基本の牛丼を食べられます。旅の最初は、歩いている道の近くにある店で十分。二度目には、気になったトッピングやセットを試すと、いつもの看板に立ち寄る楽しみができます。

海外で見た看板を、日本でも。

吉野家は米国や台湾、香港、シンガポール、タイなどにも展開しています。旅行前に知っていた店名が、日本では気軽な一食の目印に。海外とメニューが同じとは限らないので、まずは基本の牛丼を味わい、卵やトッピングで好みの一杯を探すのも楽しみです。吉野家の海外展開（英語）

写真は看板・外観の一例です。近くの店舗と営業時間は、それぞれの店舗検索で確認できます。

朝の出発前にも、ひとつ候補を。

朝食なしのホテルなら、前夜のうちに近くの店舗と営業時間を調べておくと、出発が楽になります。牛丼に加え、卵や焼き魚などの朝食メニューを用意する店もあります。駅近くの店でも、改札から歩く時間を含めて考えておきましょう。

02 / 店に入ったら

注文は、三つ決めれば大丈夫。

決めるのは、店内か持ち帰りか、どの丼か、どの大きさか。最初は「店内・牛丼・並盛」という組み合わせで考えると、選択肢がぐっと減ります。松屋では、牛丼に当たるメニュー名が「牛めし」です。並盛は標準のサイズ。もっと食べたい日は大盛、小食なら小盛やミニを探してみてください。

店員さんに伝えるなら

「牛丼、並盛をひとつ。」

Gyūdon, namimori o hitotsu.
松屋では「牛めし、並盛をひとつ」。メニューの写真を指しても伝えられます。

食券機があれば、先に注文と会計。言語の切替があれば選び、「店内 / Eat in」か「持ち帰り / Take out」へ進みます。料理とサイズを選んで会計したら、食券を取っておきましょう。番号が画面に出るセルフサービスの店では、席で待ち、呼ばれたら受取口へ。食券を店員に渡す方式の店もあります。

席のタブレットで注文する店や、店員に注文する店もあります。同じチェーンでも方式は違うので、入口の案内に合わせれば大丈夫。食後に返却口がある店では、食器をトレーごと戻します。

サラダや汁物が欲しければ「セット」を選びます。写真に卵があっても、基本の牛丼に必ず付くわけではありません。追加の卵には生卵や温泉卵があるので、好みのものを選んでください。

注文の流れの例：松屋の食券機案内・セルフサービス店の案内（英語・PDF）

自分の好みに、もうひと声。

一度食べてみると、「ごはんにつゆの味をもっとしみ込ませたい」「次は肉を多めに食べたい」と、自分の好みが見えてきます。そんなときに役立つのが、この三つの言葉です。

つゆだく TSUYUDAKU
牛肉を煮たつゆを、多めにかけてもらう注文。ごはんにも甘辛い味がよくなじみます。「牛丼、並盛、つゆだくで」と伝えてみてください。
アタマの大盛ATAMA NO ŌMORI
ごはんは並盛の量で、上にのる牛肉と玉ねぎを多めに。ここでの「アタマ」は、ごはんの上の具のこと。吉野家のサイズ名です。
肉だく NIKUDAKU
牛丼の具を、さらに追加するメニュー。吉野家では、追加分の牛肉と玉ねぎが別の小鉢で出てきます。肉をしっかり食べたい日に。

「アタマの大盛」はサイズ、「肉だく」は具の追加です。呼び名・取り扱い・つゆの調整方法は店によって異なります。注文画面に選択肢がなければ、注文するときに店員に尋ねてみてください。

用語の参考：吉野家の「だく」の説明、「アタマの大盛」の説明、肉だく牛丼

チーズも、おろしも。次は、違う一杯に。

メニューを眺めると、牛丼の上にいろいろな具が重なっています。チーズなら、甘辛い牛肉にまろやかなコクを。ピリッとした味が欲しい日は、明太子と高菜を。明太子は唐辛子などで味付けした魚卵、高菜はここでは葉野菜の漬物です。二つを合わせたり、明太マヨのソースを使ったりするメニューもあります。

さっぱりした風味が好みなら、おろしポン酢を探してみてください。「おろし」は大根おろし。柑橘の酸味がきいたポン酢と合わせると、いつもの牛丼が違う味わいになります。同じ店にもう一度入る日にも、小さな楽しみが残っています。

トッピングの組み合わせは店や時期によって異なります。メニュー例：吉野家・すき家・松屋

03 / 旅の途中で、気分を変えて

明日は、卵の丼にしてみよう。

牛丼の次に覚えたいのが、かつ丼と親子丼です。どちらも、だしのきいた甘辛い味と卵をごはんに合わせた料理。かつ丼なら豚肉の食べ応え、親子丼なら鶏肉と卵のやわらかな口当たりが楽しめます。

かつ丼 KATSUDON

とんかつの衣に煮汁がしみ、卵がからむ一杯。お腹を満たしたい昼に向いています。かつやのようなチェーンのほか、そば店などで出会うことも。卵でとじず、ソースを使う「ソースかつ丼」もあるので、写真を見ると違いが分かります。

親子丼 OYAKODON

名前の「親子」は、鶏肉と卵のこと。揚げ物よりも、やわらかな食感のものを食べたい日に選びたい丼です。手軽な店ならなか卯、鶏料理の専門店でも楽しめます。卵を半熟に仕上げたり、卵黄をのせたりする店もあります。

天ぷらが好きなら、海老や野菜の天ぷらをごはんに重ねた天丼（tendon）も候補に。天丼てんやのメニューなら、具の組み合わせを写真で選べます。同じごはんの一杯でも、煮る、揚げる、卵でとじるという違いで、食べる楽しみは変わります。

04 / この一食を、旅の予定に

少しぜいたくするなら、魚の丼へ。

食事そのものを楽しみに出かけるなら、まぐろや海鮮、うなぎの出番です。専門店で、お目当ての魚をじっくり味わう一食。気になる店を一つ見つけて、その前後に街歩きを組み合わせる。丼を目当てに、訪ねたい街が増えていきます。

まぐろを、じっくり味わう。

まぐろ丼 / MAGURODON

まぐろが好きなら、いろいろな魚がのった丼に加えて、まぐろを主役にした一杯も探してみてください。赤身、脂ののった部位、しょうゆだれに漬けた「漬け」など、同じ魚でも味わい方が広がります。

築地の海玄のような、まぐろ丼の専門店を訪ねる楽しみもあります。どの部位を食べたいか、量はどれくらいかを見比べると、一杯を選ぶ時間も楽しくなります。

築地は、東京の都心で魚介の食事や買い物を楽しめる街。場外市場の細い通りには、食材店や飲食店が並びます。卸売市場は2018年に豊洲へ移りましたが、築地の場外市場は今も街歩きと食事を楽しめる場所です。午前中に散策し、昼ごはんを目当ての店で味わう予定にしてみては。

海玄は昼営業の店。築地を歩く日の昼食候補として、営業日と当日の案内を公式サイトで確認してください。

海鮮丼は、食べたい具から選ぶ。

海鮮丼 / KAISENDON

まぐろだけでなく、さまざまな魚介を一度に味わいたいなら海鮮丼へ。刺身を盛り合わせたものが多く、丼ごとに具の顔ぶれが変わります。ウニやイクラが目的なら、それが入った丼を。いろいろ試したいなら、盛り合わせの内容を見て選ぶと満足につながります。

市場や港町の食事を旅程に入れるときは、市場そのものの時間と、食べたい店の営業時間を分けて確認しましょう。「夕方に寄れば食べられる」と考える前に、昼までの営業か、予約ができるかを見ておくと、街歩きの順番を決めやすくなります。

刺身が苦手なら、次に紹介するうなぎのように、加熱した魚の料理を選ぶ方法もあります。

うなぎには、ゆっくりする時間も。

うな丼・うな重 / UNADON・UNAJŪ

甘辛いたれを付けて焼く「蒲焼き」のうなぎは、香ばしさとやわらかな身を楽しむ料理です。丼の器なら「うな丼」、重箱に入れば「うな重」。名前だけで魚の質の上下が決まるわけではなく、うなぎの量や付け合わせも見て選びます。

専門店では、うなぎの量や焼き方、吸い物などの組み合わせも楽しみのひとつ。小ぶりな丼で味わうか、重箱いっぱいのうなぎを楽しむか。その日のお腹と相談しながら選びたい料理です。

注文から焼き上がりまで待つ店もあるため、列車に乗る直前より、その日の食事の予定として訪ねたいところ。駅からの移動時間、予約の可否、ラストオーダーまで確認しておくと、落ち着いて味わえます。

食べる場所が、ひとつ増える。

気軽な一杯と、楽しみに待つ一杯。

出発前に決めておきたいのは、どうしても食べたい丼の店と、宿の近くで使えそうな牛丼チェーン。それだけでも、旅の食事に余裕が生まれます。

昼の予定が延びた日は、近くの店で牛丼を。鶏と卵が食べたくなったら、親子丼を。そして、楽しみにしていた一杯のために、少し早く街へ出かける日があってもいい。

街で何度も見かける看板が、「ここで食べられる」という目印に変わる。その小さな安心が、次の街を歩く力になります。

食べられるものを確かめたいとき

生魚や半熟卵を避けたい場合は？

海鮮丼には刺身、親子丼やかつ丼には半熟の卵を使う場合があります。料理名だけで加熱状態は決まりません。メニューの説明や店員への確認で選び、追加の卵も種類を確かめてください。

肉を食べない人や、食材に制限がある場合は？

牛丼は牛肉、一般的なかつ丼は豚肉、親子丼は鶏肉と卵を使います。野菜の天丼でも、たれやだしに魚などを使うことがあります。具の写真だけで判断せず、店の原材料・アレルギー表示や対応方針を確認してください。
