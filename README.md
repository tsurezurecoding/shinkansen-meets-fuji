# 新幹線の窓 — 見逃さない車窓手帖 / Shinkansen Window

「新幹線の車窓を、旅の思い出と楽しみに変える」をゼロベースで形にしたリリース候補版。
ターゲットはインバウンドと日本人の両方（完全バイリンガル JA/EN）。
依存ライブラリ・バックエンドなしの静的ファイルのみで動作する。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（タイムライン生成・スタンプ帖・思い出カード・車窓図鑑） |
| `lp.html` | マーケティングLP「その147分が、旅になる。」 |
| `promo.html` | 30秒モーションプロモ（16:9ループ）。F11全画面で録画すればSNS用MP4になる。`?lang=en` で英語版 |
| `data.js` | 実写つき車窓スポット10件（バイリンガル）+ ルート定義 |
| `app.js` | 全ロジック + シーンイラスト(SVG)生成。`sceneSVG()` はLP/プロモでも共用 |
| `style.css` | 共通スタイル（夜明けの車窓パレット） |
| `images/` | 会長実写写真（富士山・熱海/相模湾・日向岡・左富士・掛川城・浜名湖・清洲城・ソーラーアーク・伊吹山・東寺） |

## コア体験（3ステップ）

1. **車窓タイムライン** — 方向と出発時刻だけで、各見どころの通過目安時刻を表示。座席選択(E/A)で自分側を強調。出発後は「つぎの車窓まであと◯分」のライブバナー。
2. **スタンプ帖** — 「見えた!」でスタンプ獲得（localStorage保存）。
3. **思い出カード** — 集めたスタンプからCanvasでシェア用カード画像を生成・保存。

## データモデルの要点

- `minutesFromTokyo`: のぞみ基準・東京発からの**目安分数**（東京→新大阪147分）。東行きは `147 - m` で反転
- 席側は方向によらず E=富士山側 / A=海側
- `category`: classic / hidden / lucky、`confidence`: verified / source-backed / needs-check
- 公開候補は会長実写がある10件に限定。写真のない候補はTODOへ退避
- 各スポットの `map` は可能な範囲で緯度経度を保持し、「地図で見る」リンクに使う
